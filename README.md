## 商用利用（ビジネス利用）における注意点

1. **プラグイン自体の利用**
    
    - 上記すべてのプラグインは MIT ライセンスで提供されているため、商用環境・社内業務での利用を含めて無料で利用Availableです。
        
2. **Obsidian本体の商用ライセンス**
    
    - プラグインは無料・商用利用Availableですが、**Obsidian本体**を商用（社内業務や営利目的）で利用する場合、従業員数や企業の形態によって **Obsidian Commercial License**（年額有料ライセンス）が必要となる場合があります。
        
3. **外部連携・API利用時の確認**
    
    - プラグインが外部のサードパーティ製サービスやWeb APIと連携する機能を持つ場合、その外部サービス側の利用規約が適用される場合があります。
